# 003. Неизвестный итог — не отказ

**Проблема.** После таймаута неясно, ушли ли деньги. Вернуть их на счёт и отправить снова — значит заплатить дважды.

**Решение.**

- Отказом считается только явный ответ провайдера. Таймаут, 5xx и обрыв переводят выплату в `Unknown`, деньги остаются на `in_transit`.
- Из `Unknown` выводит только опрос статуса по ключу.
- Ключ идемпотентности у провайдера равен id выплаты и при повторах не меняется.
- Ответу «ключ не найден» верим после паузы: исходный запрос ещё может быть в пути.
- После явного отказа создаётся новая выплата с новым ключом: старый навсегда связан с отказом.

**Аренда.** Провайдера зовём вне транзакции. Выплата берётся в аренду с токеном. Умер воркер — аренда истекла, выплата стала `Unknown`. Опоздавший воркер с чужим токеном ничего не запишет.

**На что опираемся.** На идемпотентность провайдера. Если он её не гарантирует, повтор после «не найден» надо отдавать человеку.
