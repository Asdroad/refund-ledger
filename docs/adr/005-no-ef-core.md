# 005. SQL вместо EF Core

**Решение.** Npgsql и Dapper, миграции — обычный SQL.

**Почему.** Здесь почти каждый запрос — это выбор блокировки: `for no key update`, `skip locked`, `on conflict do nothing`, условный `update`. Через EF Core большая их часть всё равно была бы сырым SQL, а трекинг изменений только мешал бы.

**Цена.** Отображение строк пишется руками, опечатку в имени столбца найдёт только тест. Поэтому слой БД проверяется на настоящем PostgreSQL, без моков.
